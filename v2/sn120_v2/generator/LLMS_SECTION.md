## Generator (SN120 mechanism 1, 10% of emission)

Generator rewards selection of math tasks whose king pass rate is informative rather than near 0 or 1. Public page: <https://affine.io/generator>. Miner guide: <https://affine.io/generator/generator-guide.md>. Kit: `v2/miner/generator_miner.py`; reference local search: `v2/miner/generator_search.py`; protocol: `v2/sn120_v2/generator/`.

Pool: the existing GitHub release `sn120-math-prior-v1`, **811,609 problems**, eight parquet shards. Use each original 20-lowercase-hex `id` verbatim. `MANIFEST.json` raw SHA-256 is `45b793b4d00d1f7225d34fd35e58018612a0ded00d96a9c23b750cfb18994115`. `generator_miner.py pool --cache DIR --index` downloads and verifies the manifest and every shard, then builds the optional pyarrow ID-membership index. No other pool or ID format is valid.

Epochs: four hours, UTC-aligned deadlines **00, 04, 08, 12, 16, 20 UTC**. Epoch ID is deadline `YYYYMMDDTHHMMZ`. Window for epoch `T` is `[T-4h,T)`, start inclusive/deadline exclusive. UTC only; never use a local time zone. The king freezes at `T` in BF16 weights and KV cache; no FP8 substitute. Seed `sha256(secret)` is committed in `state.json` at window open and the secret is revealed in results. Draw seed is `int(sha256(secret:task_id:j).hexdigest()[:12],16)`, where the secret is UTF-8 text.

Submission: **one batch per hotkey per epoch**, at most **32 distinct IDs** (minimum one). Sign the exact UTF-8 bytes `affine-generator-v1|120|1|<epoch>|<hotkey>|sn120-math-prior-v1:<manifest-sha256>|sha256(newline.join(task_ids))` with the hotkey's Ed25519 secret. The newline join preserves submitted order and has no trailing newline. `generator_miner.py build --task-ids FILE --output batch.json` uses the validator's protocol primitive; `check --batch batch.json` performs offline schema/signature/pool checks.

Activation: register an Ed25519 hotkey on netuid 120, not UID 0, and run the existing v2 activation command `python -m sn120_v2.links activate --wallet NAME --hotkey NAME --netuid 120 --network finney --execute` (omit `--execute` for dry run). Existing valid v1 activations remain valid. The kit never registers or writes chain state.

Upload: fetch `https://affine.io/generator/links/<hotkey>.json`; `generator_miner.py open-link` opens the `current` sealed box with the hotkey file/seed and prints epoch, UTC expiry and upload mode, not the URL (unless explicit `--show-url`). A separately sealed `next` grant may be available in the final ten minutes; select it with `--epoch`. `upload --batch batch.json` rechecks the batch and PUTs with the sealed headers. Presigned URLs expire no later than `T` and are secrets: never log or publish them. `first_upload_final` grants are immutable; `overwrite_until_deadline` grants permit replacement before expiry only with explicit `--replace`. **First upload wins** a contested task (timestamp tie: lower file SHA-256). Previously accepted IDs are ineligible. A task can be accepted **once ever**.

Scoring: temperature 1.0, top_p 0.95, top_k 20, max_tokens 65,536, thinking on. With `s` passes in `n` rollouts, prior **Beta(1,1)** gives posterior `Beta(s+1,n-s+1)` and `q = P(0.25 <= p <= 0.75)`. Start at 8; accept at `q >= 0.8`, reject at `q <= 0.2`, otherwise sample in steps of 8 through **8 -> 16 -> 24 -> 32**. At the final budget accept `q >= 0.5`, reject below it. These thresholds are inclusive. Local search estimates only; the validator's frozen king and committed seeds decide.

Payout: trailing **24h** (last six epochs), equal weight per accepted unique task, `w_u = A_u / sum_v A_v`, credited to the UID holding the earning hotkey at payout time. If there are no payable accepted tasks or `payout.json` is older than six hours, **100% burns to UID 0**.

Privacy: submissions are private; accepted tasks, attribution and accepted full rollouts are published; rejected submissions publish only hashes. Public files: `https://affine.io/generator/state.json`, `epochs/<epoch>/manifest.json` (hashes), `results.json`, `accepted.jsonl`, accepted-task rollouts, append-only `https://affine.io/generator/accepted-all.jsonl`, and `payout.json`. `generator_miner.py status --hotkey SS58 --epochs EPOCH` reads public state/results; add `--accepted` for accepted-all. Never publish seeds, mnemonics, private keys, private submissions, or presigned URLs.
