An upload is a new file of a miner in the object store. Its time is the upload time that the store gives (R2 LastModified). The same bytes stored again count one time. A file that a round took always counts, one time: when its miner replaced it before the record saw it, its time is the time the round took it. "Validated so far" counts the uploads that the validator called valid: at a file check, or when a round took the file. The validator checks the files when it tries to open a round and between rounds, never inside a round. So an upload during a round has no verdict until that round is over (its time limit is in miner-supply.json), and the validated count of a past hour can still grow. "≥" means at least: the store keeps one file for each hotkey, so a file that no round took and that was replaced before the record began, or in a time with no run, is not counted. Counts only: no hotkey and no time of one file. The numbers are in miner-supply.json, written each minute.
