# Default-off terminal EOS experiment

This module is an isolated experimental loss helper. Production persistent training does not import or select it. There is no worker/controller/manifest activation patch. Historical loss and optimizer behavior are preserved.

The candidate is `L_current - lambda * log p(EOS | original complete correct positive prefix)`. The explicit signed version is `terminal-eos-auxiliary-experiment-v1`, with exact fields `version`, `lambda`, `eos_token_id`, `max_output_tokens`. Lambda is finite, numeric (never bool), bounded0..0.005; the proposed first experimental arm is0.001, not an active hyperparameter. The ROOT-signed experiment must have `experiment_only: true`, `payable: false`, explicit `original_epoch`, checkpoint ID, approved original verifier public keys, and exact source hashes for both the auxiliary module and unchanged baseline objective. A separate signed native-grade receipt pins the exact original positive, batch, checkpoint, grader code and original scientific report. No signature is manufactured by the helper.

Admission independently authenticates the original ROOT-signed verifier job and manifest, worker-signed report request, exact signed commitment child batch, accepted original batch, strict fully-audited valid outcome, immutable scientific source map, original report completion inside its original job window, and separate ROOT-signed native-correct receipt. Changing tokens, labels, grader source or report bindings fails. The one-turn original output must already contain exactly one EOS as its final token and end before the output cap. No EOS is appended; early EOS, capped outputs, missing proofs, unaudited outcomes, incorrect positives and forged native receipts are refused.

`termination_auxiliary.loss` recomputes authenticated admission on each experimental call; it never accepts an externally supplied unchecked admission dictionary. It receives the same complete positive teacher-forced logits, and the caller applies the existing per-task/per-pair weight to the total loss. Only final-EOS log probability adds a term. It creates no optimizer, changes no sampler and makes no parameter update. Missing experiment returns exactly the current preference primitive; explicit lambda0 is also gradient-identical after admission. Finite final logits and complete tensor shape are required.

A future ROOT-authorized controlled run should fork two isolated nonpayable branches from exactly the same authenticated model AND persistent FP32 optimizer state. Use the same genuinely proof-audited/native-correct original pairs, lr,beta,task weights,seed and one update: current loss versus lambda0.001 auxiliary. Neither branch replaces the production lineage. Evaluate both on the untouched fixed32 cohort under identical harness/runtime/seeds/cap, measuring correctness, premature EOS, cap hits and length. Reject correctness deterioration or premature termination; reduced length alone is not convergence. This proposal addresses a measured termination failure mode, not proven causation for the earlier E16 decline.

CPU tests execute real tiny linear-model forward/backward graphs, proving historical gradients are byte-identical by default and at lambda0, and the auxiliary changes only final-EOS position gradients. Signed fixture keys/data are synthetic adversarial test fixtures; these controls are not actual native MATH or H200 qualifications. Actual E18 random32 native grading and seven original GPU-proof overlaps are separate preserved evidence. No experimental GPU job or production objective was activated.
