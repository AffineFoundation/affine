# Eight-verifier source authorization

`live-compute-source-approval-v3` is the explicit successor for a workforce of
four through eight qualified verifier identities. Earlier v1 and v2 documents
retain their four-through-six limits. Renting a machine does not enroll it.

The successor preserves the original cutover authority, ordered source archive
and complete runtime inventory, previous authorization digest, additive anchor
history, and explicit signed retirement evidence for removed identities. Once
v3 appears, a later document cannot downgrade to v1 or v2. Historical source
requests continue to use their original verifier identity scopes.

No live authority grant is created by this code change. Admission requires a
reviewed pinned source, actual runtime qualification, and an operator signature.
