# Prospective selected proof snapshots

The explicit signed policy `proof_copy_policy: {version: selected-proof-copy-v1, copy_workers: 4}` applies only to bounded sampled audits over small signed commitments with signed hourly phase bounds. Absence preserves historical whole-population snapshots. This is preparation, not authorization to modify an existing epoch.

Freeze first authenticates every discovered small canonical commitment and captures HEAD size, ETag and mining completion time for every declared child. Four metadata operations overlap. It publishes the complete surviving commitment inventories and exact captured small document bytes. A child marked `metadata_captured` has a planned public destination; it has no public proof URL and no assertion that proof bytes were copied or verified. Missing/invalid completed objects are structurally excluded; incomplete infrastructure discovery closes through the existing infrastructure-skip contract.

The fresh post-capture unpredictable seed and existing allocation/slot draw remain unchanged. The controller persists the exact original inventory/draw plan, then conditionally copies only selected child objects using the captured source ETag. Four copies overlap within the signed audit window. Destination HEAD checks size; this is explicitly not full SHA verification. Successful copy receipts bind miner, parent commitment digest, slot, source key/ETag/completion time, destination, size, declared SHA and actual timing. Transport clients have bounded connect/read timeouts and one SDK attempt. A late operation may leave forensic destination bytes but cannot become an admitted copy.

Verifier jobs include only successfully copied selected slots, with the exact copy receipts and original inventory. Worker queue admission requires the prospective source module and a timely receipt. The verifier still GETs and hashes the entire selected artifact before ordinary scientific checks. Compact training admission authenticates the same original verifier job and copied child receipt; it never reverifies with the trainer. Coverage digests use the exact original drawn inventory, excluding only renewable URLs added for admitted copies.

Unselected slots receive no audit credit or fraud label. Copy faults, source overwrites and timeouts receive typed infrastructure/budget deferrals with no redraw, training admission or fraud penalty. Completed copy results persist across retries. A process interruption before a receipt persists can repeat an idempotent conditional transport copy to the same destination; it cannot replace the source ETag, draw or scientific job.

Public history preserves every committed child’s declared metadata. It exposes proof URLs only for timely conditional copies, with declared SHA assurance until actual verifier evidence exists. Existing frozen ZIP and small-commitment historical routes retain their contracts.
