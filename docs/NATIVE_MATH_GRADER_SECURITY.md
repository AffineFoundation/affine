# Prospective native MATH grader contract

`native-math-grader-pinned-indeterminate-v1` changes future MATH epochs. Existing sealed epoch code and reports retain their original contract.

Native MATH keeps its last-complete-boxed-answer rule and native math-verify equivalence semantics. A completed correct answer scores 1; a completed incorrect answer scores 0. A grader timeout, runtime mismatch, unavailable trusted reference, or unexpected execution error is **indeterminate**, with exit status 75. It cannot qualify either side of a success/failure batch. The native Task scoring boundary raises TaskError; miners already skip these attempts and retain earlier genuine samples. Bounded verifier policy retries execution errors without miner penalties rather than certifying a negative answer.

The grader script pins Python 3.12.3, math-verify 0.9.0, latex2sympy2-extended 1.11.0, SymPy 1.14.0, antlr4-python3-runtime 4.13.2, and mpmath 1.3.0. It checks an explicit two-profile allowlist of paired interpreter executable and standard-library inventories (the observed Arbos and seven-host GPU-fleet Python 3.12.3 builds), plus the exact aggregate installed Python-file inventory for each distribution, before importing the grader or parsing submitted text. Mixing one profile’s binary with another profile’s standard library is rejected. Task setup checks `--runtime-check` readiness. The signed environment dependency map includes the approved runtime-lock digest, and the source hash includes the profile helper and grader assets. Job validation conditionally requires the helper source pin for every prospective role whose signed native MATH contract includes this marker; historical signed contracts retain their original source-pin set. Provision the approved interpreter and dependency files before admitting a role; an unlisted Python build is deliberately rejected even if its version string matches. UV preparation explicitly selects the role interpreter, and grading uses `-I -S` with a manually selected prepared site-packages path. This bypasses user-site, PYTHONPATH, .pth and sitecustomize startup code. An import guard restricts subsequent imports to the pinned standard library and five grader package roots. Run the actual readiness and answer controls on each prospective worker before deployment.

The runtime checks bind the tested grader profile; they do not provide an OS sandbox. Native MATH currently runs in a subprocess under the worker identity. Independent restricted-user/container grading, no signing-key access, no network, and external CPU/RAM/output deadlines remain defense-in-depth work. Small benign Python-string probes did not establish reachable code execution; this is not a proof of universal parser safety.

`tests/test_native_math_grader.py` runs actual bounded grading subprocesses against the approved prepared interpreter. It checks honest/wrong/arithmetic answers, last-boxed behavior, real parsing and comparison timeouts, runtime mismatch before readiness or scoring, harmless Python-string nonexecution, and the actual native Task scoring boundary. Existing miner TaskError controls and bounded-audit retry controls cover the downstream no-negative/no-penalty behavior. Local test success does not qualify a remote interpreter or demonstrate an admitted on-policy exploit.

Actual native SubprocessRuntime transport qualification additionally binds the existing fingerprinted grader interpreter in an isolated helper process and exercises its real prepare_uv_script argv, native setup, Task scoring and reference validation; no shared UV cache is modified.
