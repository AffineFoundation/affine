# Prospective compact K2/L2 qualification

This CPU-only planner creates an unsigned, default-off qualification draft from
an authentic ROOT-signed original4db miner job. It does not sign, dispatch,
change production quota or update a source seal. Run only after the original
K1/L1 E21 closes reliably. The immutable4db source, exact current model parent,
approved sampler/calibration/spec/harness and selected-token probability policy
remain pinned. Both budgets require the same newly approved max16 sampling
context; changing a contract cap or epoch changes the sampler's public draws.
The draft uses one fresh qualification epoch for both arms and removes the old
production window. ROOT must sign a fresh exact600-second window and exclusive
idle-resource scope before GPU execution, preserving every active original job.

```
python -m ops.k2l2_quota_trial --original-signed-job ORIGINAL-JOB.json \
  --authority ROOT-PUBLIC-KEY --output NEW-UNSIGNED-TRIAL.private.json
```

The plan requires compact probability artifacts, K2/L2 four distinct outcomes,
and operational search budgets8 and16 with identical sampler context. An
original contract with max_attempts8 fails closed, requiring an explicit new
ROOT-signed16-cap contract. It never silently changes old sampler receipts.
Existing backend pairing zips two positives with two negatives; existing
training averages pair losses within each task and then tasks within the update.
A task retains total gradient weight1/T and at most one valid-task point.
No implicit four-pair cross product or reward per pair is introduced.

`native_outcomes` is an independent native replay gate for the actual four
outputs. Its replay callable must come from the pinned approved native
spec/grader/tokenizer; the CPU tests use controlled native fixtures and do not
claim GPU execution. Class/reward/task/duplicate/quota mismatches reject;
grader exceptions remain infrastructure failures. This native-only gate does
not claim TOPLOC, model or sampler verification. A genuine qualification must
also run the unchanged full distribution, required TOPLOC and every-token
prescribed sampler verifier, including fresh-valid-proof off-policy tampering.

Measure completed valid tasks/minute, attempts/class distribution/cap rate,
actual unique-task and pair coverage, real transport bytes and gradient/weight
updates. Retaining twice as many trajectories and training pairs can reduce
throughput. Keep LR, beta, reference policy,600-second window and256-document
selection cap unchanged initially. Learning remains the separately authenticated
same-policy1024 fixed32 CP10/CP11 comparison, with paired gains and losses;
128-token capped outcomes and historical uncached1024 must stay separate.
